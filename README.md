# Rise & Thrive

A daily 15-minute yoga practice with optional strength training, all on one page. Each day of the week has its own routine: a 2-minute warm-up, a 10-minute core and strength sequence done in two rounds, and a 3-minute cooldown. Every pose has a picture, a countdown timer that chimes when time is up, and a check-off, so you can follow along without leaving the page. A streak counter and a monthly calendar keep track of the days you practice.

**View the page:** https://angelaor.github.io/Rise-and-Thrive/

Everything is in one `index.html` file with no build step, so it runs on GitHub Pages or any static host.

## Using the page

| Feature | What it does |
| --- | --- |
| **Day picker** | Opens that day's routine. There are 7 routines that repeat every week. |
| **Round 1 / Round 2** | Switches between the two rounds of the core sequence. Each round shows a ✓ once every pose is done. |
| **Timer** | Tap a pose's time to start the countdown. A chime plays at the end. |
| **Check-offs and reps** | Tick each pose as you finish it, or use **–** and **+** to count reps. |
| **Streak** | Counts how many days in a row you've completed your practice |
| **Strength Add-Ons** | Pick up to 3 exercises from each muscle group (Arms, Legs, Lats, Glutes, Chest, Shoulders, Back, Core, Calves). Switch between **Home** (bodyweight) and **Gym** (machines), or press **Auto Select 3** to have it choose for you. |
| **Activity Calendar** | A month view of your progress: sage green marks a yoga day, gold marks a strength day. Tap a day for details, and use **‹ ›** to change months. |

Your progress, streak, strength picks and calendar are saved in your browser, so they're still there when you come back. They're saved on that device only, so your phone and laptop each keep their own record.

## Host it on GitHub Pages

In the repository, go to Settings → Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, and save. The page will be at https://angelaor.github.io/Rise-and-Thrive/ a minute or two later.

## Pose pictures

The pose pictures are built into `index.html`, so the page needs no other files to work. The `.png` files in the repository are the original full-size pictures, kept for reference.

## A note on health

This page is for general fitness and wellbeing. It is not medical advice. If you're new to exercise, pregnant, or recovering from an injury, check with a doctor or physical therapist first, and skip any pose that causes pain.
